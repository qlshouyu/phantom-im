# 账号与用户体系

> 版本：v0.1 ｜ 优先级概览：P0 为主，第三方登录与设备锁为 P1 ｜ 上级文档：[PRD 总纲](README.md)

## 1. 功能概述

账号与用户体系是 Phantom IM 的入口层功能域，解决三个核心问题：

1. **我是谁**——用户如何创建身份（注册）、如何证明身份（登录）。
2. **别人看到的我是什么样**——个人资料（头像/昵称/ID/签名）如何设置与展示。
3. **谁能找到我、我的账号有多安全**——隐私设置控制陌生人触达我的方式，账号安全能力保护身份不被冒用或滥用。

本功能域是全产品的前置依赖：没有账号就没有关系链、没有消息、没有多端同步。因此账号相关的核心路径（注册、登录、找回）全部为 P0。

## 2. 用户场景（User Story）

1. 作为一名**新用户**，我希望用手机号+验证码快速完成注册，以便无需记忆额外密码即可开始使用产品。
2. 作为一名**海外用户**，我希望用邮箱注册和登录，以便在没有本地手机号的情况下也能使用产品。
3. 作为一名**老用户**，我希望换新手机后仍能用原账号登录并找回历史资料，以便无缝迁移到新设备。
4. 作为一名**注重隐私的用户**，我希望设置"仅通过 ID 精确搜索才能加我"，以便避免被陌生人通过手机号批量找到。
5. 作为一名**安全意识较高的用户**，我希望能查看账号近期登录设备、随时修改密码，以便在怀疑账号异常时及时止损。
6. 作为一名**决定停用产品的用户**，我希望能自助注销账号并清楚了解注销后果，以便彻底停止个人数据被使用。

## 4. 关键交互流程

### 4.1 手机号验证码注册

1. 用户在注册页输入手机号，选择区号。
2. 系统校验号码格式，触发发送验证码，按 AC-05 限频规则控制发送频率。
3. 用户输入 6 位验证码，系统在 5 分钟有效期内校验；错误累计 5 次后该验证码作废，需重新获取。
4. 校验通过后，系统创建账号，自动分配 Phantom ID，跳转至资料初始化页（设置昵称、头像，可跳过）。
5. 注册成功后自动登录，进入首页。

### 4.2 登录（验证码/密码二选一）

1. 用户输入手机号/邮箱，选择"验证码登录"或"密码登录"。
2. 验证码登录：流程同 4.1 步骤 2-3，校验通过即登录成功。
3. 密码登录：输入密码，连续 5 次错误后触发图形验证码，连续 10 次错误后锁定账号 30 分钟。
4. 若命中 AC-15 登录保护且为新设备/新地点，登录成功前需额外校验一次验证码。
5. 登录成功，写入本地登录态，跳转首页；若为账号在其他设备已登录，遵循 [多端同步与漫游](07-multi-device.md) 的多端在线策略处理会话拉取。

### 4.3 隐私设置修改

1. 用户进入"设置-隐私"页，查看当前"谁能添加我"和"如何被找到"两组开关。
2. 用户切换任一开关，前端即时提交，服务端更新生效。
3. 生效范围仅影响之后的新增查找/添加行为，已存在的好友关系不受影响。
4. 关联影响详见 [关系链](02-relationship.md) 中好友搜索与添加逻辑。

### 4.4 修改密码

1. 用户在"设置-账号安全"中选择修改密码，需先验证原密码或通过验证码验证身份。
2. 输入新密码（需满足 8-20 位、至少含字母+数字的强度要求）。
3. 提交成功后，服务端使该账号在其他所有设备的登录态失效，本设备保持登录。
4. 系统向绑定的手机号/邮箱发送一条安全提醒。

### 4.5 注销账号

1. 用户在"设置-账号安全-注销账号"发起申请，系统展示注销后果（好友关系解除、群聊自动退出、消息记录清除、ID 释放且不可找回）。
2. 用户完成二次身份验证（密码+验证码）后提交申请。
3. 账号进入 7 天冷静期：冷静期内可登录并主动"撤销注销"恢复正常状态；冷静期内该账号禁止任何主动社交行为（发消息、加好友）。
4. 冷静期结束后，系统执行账号与关联数据的永久删除，Phantom ID 被释放并进入公共号池等待重新分配。

## 5. 验收标准

**AC-01 手机号验证码注册**
- Given 用户在注册页输入一个未注册过的合法手机号，When 点击"获取验证码"并在 5 分钟内输入收到的正确验证码，Then 系统创建新账号并自动登录，跳转资料初始化页。

**AC-02 邮箱验证码注册**
- Given 用户输入一个未注册过的合法邮箱地址，When 收到验证码邮件并在有效期内正确输入，Then 系统创建新账号并自动登录。

**AC-03 验证码登录**
- Given 用户是已注册账号的手机号，When 输入正确的登录验证码，Then 系统登录成功并进入首页。

**AC-04 密码登录**
- Given 用户输入已注册账号对应的正确密码，When 点击登录，Then 系统登录成功；Given 密码连续输错 10 次，Then 账号被锁定 30 分钟并提示解锁时间。

**AC-05 验证码限频**
- Given 用户对同一手机号在 60 秒内已请求过一次验证码，When 再次点击"获取验证码"，Then 按钮保持倒计时禁用状态，不重复发送。

**AC-06 找回密码**
- Given 用户在登录页选择"忘记密码"，When 通过手机号验证码校验身份并设置新密码，Then 新密码即时生效，旧密码失效，可用新密码登录。

**AC-08 唯一 ID 分配**
- Given 新用户完成注册，When 账号创建成功，Then 系统自动生成一个全局唯一、此前未被占用的 Phantom ID 并展示给用户。

**AC-09 个人资料编辑**
- Given 用户在个人资料页修改昵称为新值并保存，When 保存成功，Then 好友列表、聊天页等所有展示该用户昵称的位置在下次刷新后更新为新昵称。

**AC-10 头像审核**
- Given 用户上传一张头像图片，When 图片经内容安全审核判定违规，Then 头像更新被拒绝，用户收到提示并保留原头像。

**AC-11 隐私设置——谁能添加我**
- Given 用户将"谁能添加我"设置为"拒绝所有人"，When 其他用户尝试通过任意方式向其发起好友申请，Then 申请被系统拦截，发起方收到"对方暂不接受好友请求"的提示。

**AC-12 隐私设置——查找方式**
- Given 用户关闭"通过手机号找到我"开关，When 其他用户使用其手机号进行搜索，Then 搜索结果为空。

**AC-13 修改密码后其他设备下线**
- Given 用户在设备 A 修改密码成功，When 设备 B 此前处于登录状态，Then 设备 B 的下一次网络请求返回登录态失效，客户端强制跳转登录页。

**AC-16 账号注销**
- Given 用户完成注销申请的二次验证并提交，When 提交成功，Then 账号进入 7 天冷静期状态，冷静期内该账号无法被其他用户搜索到，也无法发起任何主动社交行为。
- Given 账号处于注销冷静期，When 用户在期内重新登录并点击"撤销注销"，Then 账号恢复正常状态，好友关系与数据完整保留。

**AC-17 登录态保持**
- Given 用户成功登录且未主动退出，When 用户超过 24 小时未打开客户端后再次打开，Then 客户端使用本地保存的登录凭证自动续期登录，无需重新输入密码/验证码。

## 6. 边界与异常场景

- **验证码到达延迟/丢失**：提供"重新发送"入口（受 AC-05 限频约束），并提示用户检查垃圾短信/垃圾邮件文件夹。
- **弱网下注册/登录请求超时**：客户端本地保留已填写内容，请求失败后提示重试，不清空表单，避免用户重复输入。
- **手机号/邮箱被多个账号历史使用**：号码为账号的唯一登录凭证，一个手机号同一时刻只能绑定一个有效账号；号码因账号注销释放后，新用户注册使用该号码不会继承旧账号任何数据。
- **头像/昵称含违规内容**：注册资料初始化与后续编辑均需过内容安全审核，审核不通过时保留系统默认头像/昵称，不阻断注册主流程。
- **并发修改冲突**：同一账号在两台设备同时修改昵称，以服务端最后写入成功的一次为准，另一设备提交时收到"资料已更新，请刷新后重试"提示。
- **注销冷静期内被他人添加为好友**：处于冷静期的账号对外表现为"账号不存在"，无法被搜索、添加或发起会话。
- **登录保护验证码与登录验证码冲突**：验证码登录场景下，若同时命中 AC-15 新设备保护，仅需完成一次验证码校验，不重复发送第二组验证码。
- **忘记密码但验证方式全部失效**（手机号停用、邮箱无法访问）：提供人工客服申诉通道作为兜底找回方式，超出本 PRD 产品设计范围，仅作为异常兜底说明。
- **极限值**：昵称长度限制 1-20 个字符（含 emoji 按 2 字符计），签名长度限制 0-100 个字符，头像文件大小上限 10MB。
- **同一手机号短时间内重复注册尝试**：若号码已注册，注册页在校验阶段即提示"该手机号已注册，前往登录"，不重复发送注册验证码，避免与登录场景的验证码请求相互干扰。
- **账号被风控临时限制**：命中安全策略（如异常批量登录）的账号在登录成功后仍可使用，但部分主动社交行为（加好友、建群）被临时限制，具体规则见 [安全与合规](10-security.md)。

## 7. 依赖关系

- 隐私设置（AC-11、AC-12）直接约束好友搜索与添加行为，详见 [关系链](02-relationship.md)。
- 登录态与设备管理（AC-14、AC-17）与多端在线策略、消息漫游共享同一套设备与会话状态机，详见 [多端同步与漫游](07-multi-device.md)。
- 账号异常处理（连续密码错误锁定、可疑登录）与举报封禁机制共享风控能力，详见 [安全与合规](10-security.md)。
- 新设备登录后的离线消息推送提醒，详见 [通知推送](08-notification.md)。
