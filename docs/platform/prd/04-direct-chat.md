# 单聊

> 版本：v0.1 ｜ 优先级概览：P0 为主 ｜ 上级文档：[PRD 总纲](README.md)

## 1. 功能概述

单聊是 Phantom IM 最高频的核心场景：用户与某一位好友之间进行一对一消息交流。本分档聚焦单聊场景下的三类问题：

1. **会话建立**——用户如何从好友列表、搜索结果等入口进入与某人的聊天页，以及会话去重规则；
2. **消息交互**——用户在聊天页内对消息本身可执行的操作（复制、撤回、转发、引用、删除等），以及对方实时输入状态的展示；
3. **异常关系处理**——当好友关系发生变化（被删除、被拉黑）时，消息发送侧应如何提示用户，避免用户误以为消息正常送达。

单聊不涉及消息类型、消息状态（已读/送达）、撤回时限等底层规则，这些定义在 [消息能力](03-messaging.md) 中；本文档只描述这些能力在单聊场景下的呈现与交互。

## 2. 用户场景（User Story）

1. 作为用户，我希望从好友列表点击好友头像即可进入聊天页，以便快速开始一次对话，而不必先搜索或新建会话。
2. 作为用户，我希望看到"对方正在输入…"的提示，以便判断是否需要等待对方回复，减少重复提问。
3. 作为用户，我希望长按一条消息弹出操作菜单，以便快速复制、转发或引用其中的内容，而不必手动重新输入。
4. 作为用户，我希望发错话时能在短时间内撤回消息，以便避免尴尬或信息泄露。
5. 作为用户，我希望在对方已把我删除或拉黑的情况下发消息时收到明确提示，以便我知道消息实际上没有送达，而不是误以为对方已读不回。

## 4. 关键交互流程

### 4.1 从好友列表建立会话

1. 用户在好友列表点击某好友。
2. 客户端本地查询是否已存在与该好友的单聊会话。
   - 存在：直接打开该会话，定位到上次浏览位置或最新消息。
   - 不存在：创建本地会话对象（此时不产生服务端会话记录，仅在首条消息成功发送后，会话才在 [会话列表](06-conversation.md) 中正式生成）。
3. 聊天页加载最近消息（本地缓存优先展示，同时触发云端漫游拉取校验）。

### 4.2 发送消息与输入状态

1. 用户在输入框输入内容，客户端按节流（如每 3 秒一次）向对方推送"正在输入"信令。
2. 对方客户端收到信令后，将聊天页顶部展示切换为"对方正在输入…"，并启动 5 秒倒计时。
3. 若倒计时内未收到新的输入信令或收到"停止输入"信令，则恢复展示对方在线状态。
4. 用户点击发送，消息进入本地发送队列，状态变化规则遵循 [消息能力](03-messaging.md)。

### 4.3 消息操作菜单（长按/右键）

1. 用户长按目标消息气泡。
2. 客户端根据消息类型、发送方（是否本人）、消息年龄（是否超出撤回时限）动态计算可用操作项。
3. 弹出操作菜单，用户选择对应操作：
   - 复制：写入剪贴板，Toast 提示"已复制"。
   - 撤回：二次确认（仅对已超过一定停留时间的消息，如超过 10 秒需二次确认，防误触），确认后消息在自己与对方界面均替换为"你/对方 撤回了一条消息"。
   - 转发：弹出联系人/群聊选择器，支持多选目标，逐一发送该消息的转发副本。
   - 引用：目标消息缩略信息附着在输入框上方，用户输入内容后随消息一并发送。
   - 删除：二次确认后从本地消息列表移除该条消息。

### 4.4 非好友/黑名单发送拦截

1. 用户在会话内输入内容并点击发送。
2. 客户端在发送前校验当前关系链状态（好友/已删除/黑名单，规则见 [关系链](02-relationship.md)）。
3. 若判定为"我已删除对方"或"我已拉黑对方"：拦截发送，输入框禁用并展示对应提示与恢复入口（重新加好友 / 解除拉黑）。
4. 若判定为"对方已删除我"或"对方已拉黑我"：不拦截发送动作，消息正常进入发送流程，但服务端不会将消息投递给对方；客户端在下一次状态查询周期收到服务端返回的"受限投递"标记后，在会话内插入一条系统提示气泡。

## 5. 验收标准

**DC-01**
- Given 用户与好友 A 尚无单聊会话，When 用户在好友列表点击 A，Then 客户端创建本地会话并打开聊天页，展示 A 的头像与昵称。
- Given 用户与好友 A 已有单聊会话，When 用户再次从好友列表点击 A，Then 客户端打开已有会话，不产生第二个会话条目。

**DC-02 / DC-03**
- Given 用户在搜索结果或资料卡页面看到好友 A，When 用户点击进入聊天，Then 打开的会话与从好友列表进入的会话为同一会话（会话 ID 一致）。

**DC-04**
- Given 用户打开与好友 A 的聊天页，When 页面加载完成，Then 顶部展示 A 的头像与昵称（若已设置备注，展示备注名而非账号昵称）。

**DC-06**
- Given 好友 A 正在该会话输入框中输入内容，When 用户处于该聊天页，Then 顶部展示区域切换为"对方正在输入…"。
- Given 好友 A 停止输入超过 5 秒，When 用户仍停留在该聊天页，Then 顶部展示区域恢复为 A 的在线状态。

**DC-07 ~ DC-09**
- Given 用户在聊天页看到自己发送的一条 1 分钟前的文本消息，When 用户长按该消息，Then 弹出的操作菜单包含"复制、撤回、转发、引用、删除"。
- Given 该消息已发送超出撤回时限，When 用户长按该消息，Then 操作菜单不包含"撤回"选项。

**DC-10**
- Given 用户长按一条消息选择"转发"，When 用户勾选 3 个好友并确认，Then 该消息的转发副本分别出现在 3 个对应会话中，且原消息不受影响。

**DC-11**
- Given 用户对一条消息选择"引用"，When 用户输入文字并发送，Then 新消息展示为"引用内容 + 新增文字"的组合样式，接收方可点击引用内容跳转定位原消息。

**DC-12**
- Given 用户对一条消息选择"删除"并二次确认，When 操作完成，Then 该消息从本地聊天页消失，对方聊天页该消息不受影响。

**DC-15**
- Given 用户已将好友 A 从好友列表删除，When 用户打开与 A 的会话并尝试发送消息，Then 输入框被禁用，并展示"你们已不是好友，无法发送消息"提示。

**DC-16**
- Given 好友 A 已将当前用户删除（当前用户未删除 A），When 当前用户发送一条消息，Then 消息状态停留在"已发送"，会话内出现"对方可能已将你删除，消息暂无法送达"的系统提示。

**DC-17**
- Given 用户已将好友 A 拉黑，When 用户尝试在该会话发送消息，Then 发送被拦截，展示"你已将对方拉黑"提示及"解除拉黑"按钮。

**DC-18**
- Given 好友 A 已将当前用户拉黑，When 当前用户发送一条消息，Then 消息状态停留在"已发送"，且不会收到"已送达"回执，会话内提示消息可能未被看到。

## 6. 边界与异常场景

- **弱网/断网发送**：发送按钮点击后立即进入本地队列并展示"发送中"状态；网络恢复后自动重试，重试失败（如超过 3 次）标记为"发送失败"，用户可点击失败标记重发或删除。
- **撤回边界时刻**：客户端与服务端均以服务端时间戳为准判定是否在撤回时限内；用户在时限最后一秒点击撤回，若服务端判定已超时，返回撤回失败提示"消息已超过可撤回时间"，消息保持原样。
- **双端并发操作同一消息**：用户在手机撤回一条消息的同时，在桌面端对该消息发起转发，服务端以撤回事件的时间戳为准，若转发请求发起时消息尚未标记撤回，转发内容按撤回前的原文快照生成，不因后续撤回而失效（转发副本是独立消息）。
- **合并转发数量上限**：多选转发单次最多支持 30 条消息（含图片/文件等），超出提示"最多可选择 30 条消息"。
- **关系状态查询延迟**：DC-16/DC-18 中"对方已删除/拉黑我"的判定依赖服务端异步返回，存在数秒延迟窗口；此窗口内消息展示为"已发送"，延迟到达后再补充系统提示，不追溯修改已展示的消息状态图标。
- **对方主动重新加回好友**：若对方后续重新添加当前用户为好友，历史会话解除发送限制，此前的系统提示气泡保留在聊天记录中作为历史轨迹，不自动清除。
- **输入状态高频抖动**：用户快速输入又删除内容导致输入信令频繁触发，客户端按节流策略（最短间隔 3 秒）合并信令，避免"正在输入"状态在对方界面闪烁。
- **超长文本消息复制**：复制操作对超长文本（如超过 5000 字）同样支持，无长度上限。
- **多设备同时打开同一会话**：用户在手机与桌面端同时打开与同一好友的会话，任一端的撤回/删除操作需实时同步至另一端，正在浏览中的另一端消息应即时刷新为撤回/删除后的状态，不需用户手动刷新。
- **恢复好友关系后的历史提示气泡**：DC-16 场景中插入的系统提示气泡不会因关系恢复而自动清理，避免篡改聊天记录的真实轨迹；若用户对该提示反感，可通过"删除消息"手动移除该条系统提示。
- **引用消息被删除后的展示**：用户引用了一条消息发送，若原消息随后被发送方撤回或本地删除，接收方点击该引用块时提示"原消息已被撤回/删除"，不影响引用块本身文字内容的正常展示。
- **黑名单状态切换的实时性**：用户刚拉黑对方后立即返回聊天页尝试发送消息，客户端需以本地最新关系状态（而非缓存）为准立即拦截，避免出现"拉黑生效前发出的最后一条消息"绕过限制的情况。
- **转发目标包含受限关系**：用户多选转发消息，目标列表中若包含"已删除我"或"已被我拉黑"的好友，该目标在选择器中置灰不可选，避免转发后触发与 DC-15~DC-18 相同的送达异常。
- **账号注销后的会话展示**：若对方账号已注销，聊天页顶部头像/昵称展示为"已注销账号"占位信息，历史消息保留可查看，输入框禁用禁止发送新消息。
