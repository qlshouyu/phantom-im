本技能指导创建独具特色、多浏览器兼容、生产级的前端界面，避免千篇一律的"AI 风格垃圾"美学。实现真正可运行的代码，在审美细节和创意选择上展现非凡的关注。
用户提供前端需求：要构建的组件、页面、应用或界面。他们可能会附带关于目的、受众或技术约束的上下文信息。
## 设计思维

在编码之前，理解上下文并确立一个**大胆的**审美方向：
- **目的**：这个界面解决什么问题？谁来使用？
- **基调**：选择一个极致方向：极简主义、极繁主义、复古未来主义、有机/自然、奢华/精致、俏皮/玩具感、编辑/杂志风、粗野/原始、装饰艺术/几何、柔和/粉彩、工业/实用主义等等。可选的风格非常多。以此为灵感，但要设计一个忠于审美方向的作品。
- **约束**：技术要求（框架、性能、可访问性）。
- **差异化**：是什么让这个作品**令人难忘**？人们会记住的那个独特之处是什么？
**关键要点**：选择一个清晰的概念方向并精确执行。大胆的极繁主义和精致的极简主义都可行——关键在于意图性，而非强度。

然后实现可运行的代码（HTML/CSS/JS、React、Vue 等），代码必须：
- 多浏览器兼容
- 生产级且功能完备
- 视觉冲击力强、令人难忘
- 风格统一，有明确的审美视角
- 在每个细节上精雕细琢

## 前端美学指南
关注重点：
- **字体**：选择漂亮、独特、有趣的字体。避免使用 Arial 和 Inter 这类通用字体；应选择能够提升前端美学的、独具特色的字体；选择出人意料、有个性的字体。将一款特色显示字体与一款精致的正文字体进行搭配。
- **色彩与主题**：致力于打造统一的美学。使用 CSS 变量保持一致性。主导色配以醒目的强调色，优于胆怯、平均分布的调色板。
- **动效**：将动画用于效果和微交互。HTML 中优先使用纯 CSS 解决方案。在 React 中可用时使用 Motion 库。聚焦高光时刻：一次精心编排的页面加载（带有 animation-delay 的错落式入场）比分散的微交互能带来更多惊喜。运用滚动触发和出人意料的 hover 状态。
- **空间构图**：出人意料的布局。不对称。重叠。对角线流动。打破网格的元素。慷慨的负空间或受控的密集感。
- **背景与视觉细节**：创造氛围与深度，而不是默认使用纯色。添加与整体美学相匹配的情境化效果与纹理。运用创意形式，如渐变网格、噪点纹理、几何图案、分层透明度、戏剧性阴影、装饰性边框、自定义光标和颗粒叠加。
**绝不**使用千篇一律的 AI 生成美学，例如过度使用的字体家族（Inter、Roboto、Arial、系统字体）、陈词滥调的配色方案（特别是白底紫色渐变）、可预测的布局和组件模式，以及缺乏上下文特色的模板化设计。
要富有创意地诠释，做出感觉是为特定情境真正设计的、出人意料的选择。每个设计都应不同。在浅色和深色主题之间变换，使用不同的字体、不同的美学。**绝不**在每次生成中都收敛到常见选择（例如 Space Grotesk）。
**重要提示**：让实现的复杂度与审美愿景相匹配。极繁主义设计需要繁复的代码、丰富的动画和效果。极简或精致的设计则需要克制、精准，以及对间距、字体和微妙细节的悉心关注。优雅源自对愿景的出色执行。

## 与 spark 家族协作（渐进式加载）

本技能只负责"设计得好看"。**跨浏览器一致**与**安全无漏洞**由另外两个姊妹技能承担。它们的内容**不在此处内联**——只在命中下表条件时，建议通过 `Skill` 工具按需加载，以节省上下文。**不要预先全部加载，也不要用 `@` 路径强制读取。**

| 阶段 | 何时建议触发 | 加载方式 |
|------|------------|---------|
| ① 设计实现 | 默认——本技能本体，先出稿 | 当前技能 |
| ② 跨浏览器适配 | 界面成型后做兼容审计；用户报告"某浏览器样式/交互异常"；需多设备/响应式适配 | 建议用 `Skill` 工具加载 `spark-cbc` |
| ③ 安全 | 渲染来自用户 / AI / RAG / 第三方的不可信内容；用到 `innerHTML` / `v-html` / `dangerouslySetInnerHTML` / `{@html}` / `insertAdjacentHTML`；上线前安全自检 | 建议用 `Skill` 工具加载 `spark-frontend-sec` |

- **按需而非默认**：仅当命中上表触发条件时才加载对应技能；未命中则无需加载，保持轻量。
