## ADDED Requirements

### Requirement: 发送指令隔离与有界背压

网关 MUST 将 `SendMsgReq` 的完整业务处理移出 WebSocket 网络 I/O 线程，并使用按连接串行、进程级有界的工作队列执行。同一连接的发送请求 MUST 保持提交顺序；队列满或处理超时时 MUST 返回可重试错误，且 MUST NOT 静默丢弃请求或关闭正常心跳连接。

#### Scenario: 慢发送不阻塞后续帧
- **WHEN** 同一连接连续提交两个发送请求，第一条请求的下游处理耗时较长
- **THEN** WebSocket I/O 线程仍可继续接收帧，第二条请求在第一条完成后按提交顺序处理

#### Scenario: 有界队列拒绝过载
- **WHEN** 发送工作队列达到容量上限
- **THEN** 网关返回可重试的失败响应并保持连接和心跳有效，不执行未受理的消息

#### Scenario: 单连接处理异常不影响其他连接
- **WHEN** 某连接的发送任务抛出未处理异常
- **THEN** 仅在对应请求上返回失败结果，其他连接的任务和 WebSocket I/O 线程不受影响
