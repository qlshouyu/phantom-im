## ADDED Requirements

### Requirement: 本地消息缓存合并持久化

SDK SHALL 合并短时间内的消息缓存变更并延迟持久化，单条消息的正常追加和重排 MUST NOT 多次同步序列化全部会话缓存。持久化 MUST 在有限延迟内完成，并在页面隐藏、退出登录或显式刷新状态前尽力落盘；写入失败 MUST NOT 阻塞事件回调或消息发送。

#### Scenario: 单条消息合并写入
- **WHEN** SDK 因收到一条消息连续执行追加、重排和状态回填
- **THEN** 这些变更合并为一次待执行的本地持久化，而不是每次变更都同步序列化全部缓存

#### Scenario: 短时间多条消息合并持久化
- **WHEN** SDK 在持久化延迟窗口内连续处理多条消息
- **THEN** 多次缓存变更合并为有限次写入，最终持久化内容包含全部已应用消息

#### Scenario: 页面隐藏前刷新缓存
- **WHEN** 页面进入隐藏状态且仍有待持久化的消息变更
- **THEN** SDK 尽力立即写入最新缓存，避免已展示消息在正常刷新后丢失

#### Scenario: 本地存储失败不影响消息处理
- **WHEN** `localStorage` 写入抛出容量或权限错误
- **THEN** SDK 吞掉持久化错误并继续向宿主触发消息事件，不阻塞网络收发
